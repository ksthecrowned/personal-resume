## 5. Recommandations d’amélioration (contenu) — brouillon pour la suite

Ces points sont des **pistes de design / rédaction**, pas encore validées ligne par ligne.

### Forts à garder et renforcer

1. **LRC / TPE / NFC / systèmes transactionnels** — différenciant pour un terminal (équipements, parcours, fiabilité). Quantifier si possible (volumes, disponibilité, nb terminaux, délais).  
2. **Reprise de legacy sous-documenté** — très crédible en SI industriel / ops.  
3. **Parcours Webtinix (IC → Team Lead → Adjoint DT)** — montrer progression + encadrement (taille d’équipe déjà citée : 5).  
4. **Production / incidents** — garder les preuves chiffrées déjà utilisées ailleurs (−70 % incidents critiques, etc.) si toujours exactes.  
5. **Ancrage local** Pointe-Noire — utile pour Congo Terminal.

### À densifier / clarifier (zones d’amélioration)

1. **Profil** trop généraliste “full-stack 5 ans” → 4–6 lignes **orientées SI & projets** + mots-clés Congo Terminal / logistique digitale (intégration, fiabilité, production, systèmes métier).  
2. **Manque de chiffres** sur plusieurs bullets (utilisateurs Ride, nb TPE, charge e-commerce, taille équipes consulting). Ajouter uniquement des faits vérifiables.  
3. **Noms de produits** (Ride, DTMoney, MyTélévision, D5News…) : utiles pour crédibilité ; les réintroduire explicitement dans le CV ATS si possible.  
4. **Formation** Licence II éco vs titre “Ingénieur” : anticiper la question — cadrer par **expérience 5+ ans** / responsabilités techniques (ne pas inventer un diplôme d’ingénieur).  
5. **Anglais “conversationnel”** : fragile si AGL attend bilingue sur certains postes — soit monter le niveau réel, soit formuler honnêtement sans surpromettre.  
6. **Bloc IA** : pertinent, mais **secondaire** pour Congo Terminal ops — 2–3 puces max, pas une colonne entière.  
7. **Certifs Udemy / ZTM** : valeur ATS faible pour un terminal ; garder 1 ligne compacte ou retirer si manque de place.  
8. **Centres d’intérêt** : couper ou 1 ligne ; mangas/JV peu utiles ici.  
9. **Qualités** : fusionner dans le profil / expériences (les listes de soft skills ATS-pures ajoutent peu).  
10. **Projets perso** : TimeGate (accès / NFC / RH) est le plus aligné — garder ; Paradis / StoryForge en une ligne chacun ou sortir selon l’espace.  
11. **Deux numéros de téléphone** : OK, mais format ATS propre (libellés clairs).  
12. **Cohérence dates** Webtinix vs consulting parallèle — vérifier formulation pour éviter l’impression de chevauchement confus.

1. En-tête (nom, titre verrouillé, contacts, liens)
