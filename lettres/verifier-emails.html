Vérification des emails RH

Contrôle des adresses de data/spontanees.json avant envoi. La présence d’un MX confirme le domaine ; le test SMTP RCPT (optionnel) donne un indice sur la boîte, sans garantie absolue.

Syntaxe + MX : bun run verify:emails
+ SMTP RCPT : bun run verify:emails -- --smtp
Puis recharge cette page (/lettres/verifier-emails.html via bun run preview).
