Modules que je suis prêt à animer, sur la base de plus de cinq ans d'expérience en développement web et mobile en production, d'encadrement d'équipe et de livraison de projets e-commerce, fintech et médias.

Modules prioritaires

1. Développement Web

Conception et réalisation d'applications web : HTML, CSS, JavaScript, PHP, frameworks front (React / Next.js) et back (Node.js, Laravel).

  • Architecture client/serveur et APIs REST
  • Intégration d'interfaces et bonnes pratiques front-end
  • CMS : WordPress, PrestaShop (e-commerce)

2. Développement Mobile

Applications mobiles cross-platform avec Flutter et React Native ; publication, maintenance et intégration avec des APIs back-end.

  • UI mobile, navigation et consommation d'API
  • Cas concrets : apps de livraison et transactions

3. Génie Logiciel

Cycle de vie logiciel, organisation de projet, qualité et mise en production à partir de retours d'expérience terrain.

  • Analyse de besoins, découpage et livraison itérative
  • Code reviews, documentation, gestion des incidents
  • Collaboration produit / design / technique

4. Bases de données

Modélisation et exploitation de bases relationnelles (MySQL, PostgreSQL) dans des applications web réelles.

  • Modèle relationnel, requêtes SQL, intégrité des données
  • Lien ORM / API et bonnes pratiques de sécurité

Modules complémentaires (selon besoin)

5. Informatique de gestion

Outils numériques métier, automatisation et applications de gestion ; lien entre besoins business et solutions techniques.

6. Introduction à la cybersécurité

Sensibilisation aux risques web, bonnes pratiques de sécurisation des applications et veille (certification Ethical Hacking — Udemy).

Approche pédagogique : cours magistraux courts, ateliers pratiques, projets fil rouge inspirés de cas réels, et évaluation par livrables. Disponible pour adapter le contenu aux programmes L1 / L2 / L3 d'IPAIM University.
